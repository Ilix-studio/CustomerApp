## Project state

Local Mart — a hyperlocal shopping app (Expo SDK 57, React Native 0.86, React 19.2, TypeScript strict). `design.md` at the repo root is the source of truth for the home screen's look, tokens and behavior. Wallet and search are still `PlaceholderScreen` stubs.

- The package manager is npm (no `bun.lock`), so use `npx`. Run `npm install` if `node_modules/` is missing.
- `npx tsc --noEmit` needs `expo-env.d.ts` and `.expo/types` (both gitignored, generated by `npx expo start`). Without them, CSS-module imports fail to typecheck and typed routes go unchecked.
- No test framework is configured (no Jest). If tests are needed, follow https://docs.expo.dev/develop/unit-testing/.
- `src/components/{themed-text,themed-view,animated-icon,external-link,hint-row,web-badge,ui/collapsible}`, `src/constants/theme.ts` and `src/hooks/use-{theme,color-scheme}*` are leftovers from the create-expo-app template and aren't used by the app. `npm run reset-project` is a template script that moves `src/` away; don't run it.

## Architecture

- **Routing**: `src/app/_layout.tsx` loads Plus Jakarta Sans (holding the splash until ready), provides `AppStateProvider`, and renders a root `Stack`. The `(tabs)` group uses headless `expo-router/ui` `Tabs` with a hidden `TabList` as the route registry. The visible bar is `BottomNav`, rendered by `FloatingBottomAreaProvider` together with the dismissible `FreeDeliveryBar` (home only). Adding a tab means adding a route in `src/app/(tabs)/` **and** an entry in `navTabs` (`src/components/navigation/bottom-nav.tsx`).
- **Floating bottom area**: it's absolutely positioned over the content. Scroll screens inside tabs must pad their content with `useFloatingBottomInset()` so the last items aren't covered.
- **Design tokens**: `src/constants/tokens.ts` (palette, service/tile tint tables, typography variants, spacing, radii, sizes, shadow). Never hard-code hex values in components. Use `AppText` (`variant` + `color` token) for text and `Icon` (`src/components/ui/icon.tsx`) for icons. Fonts are one family per weight via `fontFamilies`, so don't use `fontWeight`.
- **Icons**: Lucide (`lucide-react-native`), stroke style. Data refers to icons by string name; add new ones to the registry in `icon.tsx`. No emoji.
- **Backend**: `src/store/` is Redux Toolkit Query against `localMart-BE` (`EXPO_PUBLIC_API_URL`): `product-api.ts` (catalog) and `customer-api.ts` (sign-in, profile, addresses, orders, restaurants). Auth is in `slices/auth-slice.ts` (SecureStore) and the cart in `slices/cart-slice.ts`. Screens: `sign-in`, `checkout`, `address`, `profile`, and the Order Again tab (your orders, polled every 20s). A cart with several shops' items becomes one order per shop. Real sign-in is Firebase phone OTP, which is **not wired**: it needs `@react-native-firebase/auth` in a dev build (see `src/lib/phone-auth.ts`). Until then a development-only phone sign-in works against a local backend with `ALLOW_DEV_LOGIN=true`; the backend 404s it in production.
- **Data**: home content (chips, banner, services, rails, search hints) comes from `fetchHomeFeed()` in `src/data/home-api.ts`, currently returning `mock-home-feed.ts` after a fake delay. Types are in `src/data/types.ts`; tint and icon fields are token/registry keys, not colors. Swap the API body for the real backend. `useHomeFeed()` exposes loading/error/ready, and each home section has a matching `*Skeleton`.
- **Placeholders**: the address, wallet balance and cart count are in `src/state/app-state.tsx`, seeded from `placeholderSession` in `src/config/app-config.ts`, along with `freeDeliveryThreshold`. Format money with `formatCurrency`.
- **Web is statically rendered** (`web.output: "static"` in `app.json`). Avoid reading client-only state during the initial render on web.
- **Imports**: path aliases `@/*` → `src/*` and `@/assets/*` → `assets/*`.
- **Config flags** (`app.json`): `typedRoutes` (route strings in `Link`/`router` are type-checked) and `reactCompiler` (avoid manual `useMemo`/`useCallback` unless profiling shows a need). URL scheme is `customerapp`.
